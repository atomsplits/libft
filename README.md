# Description
The very first project of the 42 curriculum; a library that contains all necessary functions that will be used in future projects.
This library contains the recreations of many standard C functions, and functions that are not included in C.
Linked list manipulation functions are also included in this library, along with a Makefile to compile the whole thing.

# Instructions
`git clone https://github.com/atomsplits/libft` and `make`
